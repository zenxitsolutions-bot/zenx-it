## 4. Remove self-registration

1. Remove "Create an Account" / Sign Up completely from admin, dietitian and client login
   pages — the UI, the routes, and the backend registration endpoint. Self-registration must
   be impossible, not just hidden. Keep email/password, Login, and Forgot Password.

## 2.1 Dietitian first login — forced password change

2. Dietitian first login: add a mustChangePassword flag, default true for accounts created
   by admin. On login, if the flag is true, force the password-change screen and block every
   dashboard route until the password is changed successfully. Enforce this on the server too —
   reject API calls from a dietitian whose flag is still true, except the change-password call.
3. After a successful change, clear the flag and let them into the dashboard.

Verify: an admin-created dietitian cannot reach the dashboard by typing the URL directly.
