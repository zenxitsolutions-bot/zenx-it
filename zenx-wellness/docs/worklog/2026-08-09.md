## Decisions made
- Report file storage: local disk under `server/uploads/` for now (flagged as an open assumption
  in the plan, not decided silently) — rules out any cloud-storage code until that's confirmed.
- shadcn preset **Nova** (radix base) re-themed via CSS variables rather than a custom preset —
  keeps upstream `shadcn add` updates working, rules out hand-rolling primitives from scratch.
- Ownership/authorization logic lives in controllers, not a generic CRUD factory — the
  client/dietitian/admin scoping genuinely differs per resource, so one factory would need more
  config than it saves.

## Problems hit & how they were solved
- `npx shadcn@latest init -y` still opened an interactive preset picker → fixed by passing
  `-p nova` explicitly.
- shadcn's Nova preset overwrote `index.css` with Geist font + neutral oklch theme → rewrote the
  semantic tokens (`--background`, `--primary`, `--sidebar-*`, etc.) onto the legacy palette and
  removed the now-unused `@fontsource-variable/geist` dependency.
- Tailwind v4 warned that the Google Fonts `@import url(...)` didn't precede all other rules →
  moved it above `@import 'tailwindcss'` in `index.css`.
- `vite.config.js` warned `__dirname` is unsupported by the native config loader → switched to
  `fileURLToPath(import.meta.url)`.
- Leftover Vite dev-server process on Windows didn't die from `kill`/MSYS PID — needed
  `taskkill.exe //PID <winpid> //F` using the WINPID from `netstat.exe`, not the MSYS PID.
